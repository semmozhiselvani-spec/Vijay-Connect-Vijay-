🎉 Festival / Offer Opening Banner

Use the existing 1-second opening banner only during a festival or offer period. Set the start and end time in IST. Outside this period it stays completely hidden.

Example: New Year — Start 01/01/2027 00:00, End 02/01/2027 00:00. The banner appears for the selected duration whenever a visitor opens the home page during that period. When the period ends, it automatically disappears.

🎉 Festival Banner — One Slot Only

Only one festival banner is stored at a time. To change Pongal to Diwali, delete the current banner first, then add the new one and Publish.
